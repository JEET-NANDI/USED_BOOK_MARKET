# USED BOOK MARKET

A student-to-student marketplace for buying and selling used books,
notes, and study materials.

## Main Features

- Buy used books
- Sell used books
- Sell purchased books again
- Search and filter books
- Automatic buyer price calculation
- Buyer dashboard
- Seller dashboard
- Admin dashboard
- Order management
- Payment management
- Reviews and ratings

## Project Structure

- frontend → Main user website
- backend → Backend API
- admin-dashboard → Admin panel
- database → Database files
- docs → Project documentation
